부동산 AI 도우미 — 유튜브 인사이트 + 실데이터 교차검증 카카오톡 리포트를 발송합니다.
(지메일 발송은 폐기됨. 카카오톡이 유일한 전달 채널입니다.)

레포지토리: sdgsdgdsgdsgsd/coupang-dashboard
브랜치: claude/realestate-youtube-crawler-mt0rmw

---

**Step 1: 오늘 날짜 확인 (KST)**
KST(UTC+9) 기준 오늘 날짜를 YYYYMMDD 형식으로 확인.

**Step 2: 데이터 로드**
git pull 후 다음 파일을 읽으세요 (로컬에 없으면 GitHub MCP get_file_contents 사용):
- data/report_{오늘날짜}.json (Claude API 1차 분석 결과 — 있으면 활용)
- data/raw_videos_{오늘날짜}.json (원본: title, url, channel_name, views, description, transcript)
- 오늘 파일이 없으면 어제 날짜도 시도.
- 둘 다 없으면 GitHub Actions 워크플로우(daily_report.yml)를 mcp__github__actions_run_trigger로 수동 실행하고 완료 후 데이터를 다시 읽으세요. (이 세션에서는 Apify 접근이 네트워크 정책으로 차단되어 로컬 크롤링 불가)

**Step 3: 유튜버 주장 분석**
transcript를 부동산 전문가 시각으로 읽고:
1. 핵심 인사이트 5개 (여러 채널 공통 강조점, 근거 포함)
2. 시장 감성 (긍정/중립/부정 + 근거 1~2문장)
3. 리스크 3개 / 투자 기회 3개 / 정책·이슈 2개
4. **영상에서 언급된 구체적 지역명·아파트명·가격 주장을 모두 추출** (Step 4 검증 대상)

**Step 4: PlayMCP 실데이터 교차검증 (핵심!)**
Step 3에서 추출한 지역/아파트에 대해 PlayMCP 도구로 실제 데이터를 조회:
- mcp__PlayMCP__kakaoRealEstate-get_market_price / search_property → 실제 시세·매물
- mcp__PlayMCP__AptInfo-get_region_code → 지역코드 → AptInfo-get_apt_list / get_apt_price / get_apt_info → 실거래가
- mcp__PlayMCP__NaverSearch-search_news → 언급된 정책·이슈의 최신 뉴스 확인

유튜버 주장 vs 실데이터를 비교해서:
- 주장이 실거래가와 일치하는지 / 과장인지 / 시차가 있는지 판단
- 각 검증 항목마다 "일치 ✅ / 과장 ⚠️ / 확인불가" 판정

**Step 5: 카카오톡 발송 (모바일 가독성 최우선)**
mcp__PlayMCP__KakaotalkChat-MemoChat으로 아래 형식 그대로 발송.
카카오톡 모바일 화면은 한 줄에 한글 약 18~24자만 들어갑니다. 반드시 아래 규칙을 지키세요.

**작성 규칙 (엄수):**
- 각 항목은 "짧은 헤드라인(12자 이내) + 다음 줄에 부연(24자 이내 한 줄)" 2단 구조.
  → 완결된 긴 문장을 한 불릿에 통째로 넣지 말 것 (모바일에서 3~4줄로 감김).
- 인사이트·검증·영상 항목은 **각 항목 사이에 빈 줄 1개**.
- 인사이트는 1️⃣2️⃣3️⃣… 번호 이모지로 시작.
- 검증은 판정 이모지를 줄 맨 앞에: ✅ 부합 / ⚠️ 과장·배치 / ❓ 확인불가.
- 리스크·기회·정책은 짧으므로 `•` 목록으로 묶고 각 항목 한 줄 유지.
- 구분선은 짧게 `━━━━━━` (긴 선은 모바일 폭 초과).
- 조회수는 만 단위 축약("3.6만회").
- 항목 수: 인사이트 5 / 검증 2~3 / 리스크 3 / 기회 3 / 정책 2 / 영상 3.
