카카오톡으로 발송합니다. (지메일 발송은 폐기됨. 카카오톡이 유일한 전달 채널입니다.)

**Step 1: 오늘 날짜 확인 (KST)**
KST(UTC+9) 기준 오늘 날짜를 YYYYMMDD 형식으로 확인.

**Step 2: 데이터 로드**
git pull 후 다음 파일을 읽으세요 (로컬에 없으면 GitHub MCP get_file_contents 사용):
- data/report_{오늘날짜}.json (Claude API 1차 분석 결과 — 있으면 활용)
- data/raw_videos_{오늘날짜}.json (원본: title, url, channel_name, views, description, transcript)
- 오늘 파일이 없으면 어제 날짜도 시도.
- 둘 다 없으면 GitHub Actions 워크플로우(daily_report.yml)를 mcp__github__actions_run_trigger로 수동 실행하고 완료 후 데이터를 다시 읽으세요. (이 세션에서는 Apify 접근이 네트워크 정책으로 차단되어 로컬 크롤링 불가)

**Step 3: 전문가 관점 분석 (표면 요약 금지)**
transcript를 부동산·주식 시장 전문가 시각으로 분석합니다.
**절대 유튜버가 한 말을 그대로 재진술하지 마세요.** 여러 영상의 주장을 종합해서
당신 자신의 전문가적 판단·해석을 제시해야 합니다.

1. **핵심 인사이트 3~4개** (카카오톡 메시지 글자 수 한도 때문에 5개에서 축소) — 각 인사이트는
   다음 3파트로 **명확히 분리**해서 작성 (한 문단에 뭉쳐 쓰지 말 것 — 이유는 Step 5 포맷 참고):
   - **헤드라인**: 해석이 담긴 한 줄 (12~15자 내외)
   - **설명**: [관찰된 사실/주장] → [그것이 의미하는 바에 대한 당신의 해석]을 **1문장**으로 압축
   - **체크포인트**: "그래서 다음에 뭘 더 봐야 하는지"를 완결된 문장이 아니라 **키워드/구 형태로
     10~15자 내외**로, 설명과 **같은 줄에 괄호로 병기** (예: "...(🔎 SK하이닉스 실적발표일)")
   - 나쁜 예(재진술): "삼성전자·SK하이닉스는 조정 국면이나 홀드가 맞다는 의견"
   - 좋은 예 (헤드라인+설명+체크포인트를 2줄로):
     "삼성전자 실적, 예상을 뛰어넘었다
     2Q 영업이익 89.4조(전년비1810%↑)로 세계1위 — 홀드 논리가 오히려 보수적이었던 셈. (🔎 SK하이닉스 실적발표일)"
   - Step 4의 실질 현황 조사 결과를 먼저 파악한 뒤, 그 결과(부합/과장/의외의 발견)를 설명 문장에
     녹여서 "동의한다/반박한다/유보한다"는 입장을 명시할 것. 조사와 인사이트가 따로 놀지 않게.
   - 설명+체크포인트를 합쳐 반드시 1문장 분량까지만 — 길게 풀지 말 것 (Step 5의 글자 수 한도가
     엄격하므로 매우 중요).
2. 시장 감성 (긍정/중립/부정 한 단어 + 짧은 근거 구, 문장으로 풀지 않아도 됨)
3. 리스크 2개 / 투자 기회 2개 / 정책·이슈 2개 (5개 항목에서 축소) — 유튜버 주장의 재진술이
   아니라 실질 현황 조사·거시 맥락을 결합한 당신의 평가로, 각 한 줄로 작성
4. **영상에서 언급된 구체적 지역명·아파트명·종목명·가격 주장을 모두 추출** (Step 4 조사 대상)

**Step 4: PlayMCP로 실질 시장 현황 조사 (핵심! — 단순 검증이 아니라 독립적 리서치)**
영상은 리서치의 출발점일 뿐입니다. 언급된 내용을 확인하는 수준을 넘어서 실제 시장이 어떻게
움직이고 있는지 스스로 조사하세요:

- **지역 확장 조사**: 영상이 언급한 지역/단지뿐 아니라 인접·비교 지역까지 조회
  (예: 성동구가 언급되면 마포구·강남구 등 비교 지역도 함께 조회해 상대적 위치 파악)
- **추이 파악(스냅샷 금지)**: `AptInfo-get_apt_price`를 최근 2~3개월치 반복 호출해서
  상승/하락/보합 방향성을 확인. 한 달치 숫자만 보고 끝내지 말 것
- **호가-실거래 스프레드**: 특정 단지가 언급되면 `kakaoRealEstate-search_property`로
  현재 매물 호가와 최근 실거래가를 비교해 괴리(과열/조정 신호)를 확인
- **뉴스 맥락화**: `NaverSearch-search_news`로 관련 정책·규제·금리 이슈를 한 건이 아니라
  여러 건 검색해서 맥락을 파악 (예: 규제 발표 전후 반응, 후속 보도 등)
- **주식 종목도 동일**: 언급된 종목명·섹터에 대해 최신 뉴스를 복수 검색해 흐름을 파악
- 자막이 없는 영상은 재구술하지 말고 "자막없음, 실데이터로 대체분석"이라 명시한 뒤,
  제목의 지역명을 위 수준(추이·비교지역·복수뉴스)으로 깊이 있게 조사해 보완할 것

조사 결과를 바탕으로 유튜버 주장과 대조해 각 항목마다 "일치 ✅ / 과장 ⚠️ / 확인불가 ❓" 판정.
판정에서 끝내지 말고 조사 과정에서 발견한 흥미로운 지점(예상외 수치, 지역 간 격차, 추이 반전 등)도
함께 기록해 Step 3 인사이트에 반영할 것.

**Step 5: 카카오톡 발송 (반드시 단일 메시지, 850자 이내)**
mcp__PlayMCP__KakaotalkChat-MemoChat으로 아래 형식 그대로, **한 번만** 호출해서 발송.

**⚠️ 길이 한도 (실측으로 확정됨 — 반드시 준수):**
"카카오톡은 글자 수 제한이 없다"는 가정은 틀렸음이 실측으로 확인됨. 100자 단위 위치 마커를
넣은 순수 텍스트로 테스트한 결과, **문자 수 기준 약 900~1000자에서 말 없이 잘림**
(바이트 기준이 아니라 글자 수 기준 — 이모지 유무와 무관하게 900자 근처에서 컷됨).

- **목표: 전체 메시지 850자 이내(공백 포함)**. 900~1000자 한도에서 안전마진을 둔 수치.
- **분리 발송(여러 통으로 나눠 보내기)은 하지 말 것 — 무조건 한 통으로 발송.**
- 작성 후 반드시 대략적인 글자 수를 세어볼 것. 850자를 넘으면 아래 우선순위로 줄일 것:
  ① 리스크/기회/정책 항목을 2개→1개로 축소
  ② 핵심 인사이트를 4개→3개로 축소
  ③ 각 인사이트 설명을 더 짧게, 분석영상을 2개로 축소
- 섹션 구분선(`━━━━━━`)은 각 섹션 **헤더 위에 한 번만** 사용 (헤더 아래는 생략해 공간 절약).

**작성 규칙:**
- 인사이트: 헤드라인(한 줄) + 설명 1문장(체크포인트는 문장 끝에 괄호로 병기, 별도 줄 쓰지 않기).
- 리스크·기회·정책은 `•` 목록, 각 한 줄.
- 인사이트는 1️⃣2️⃣3️⃣ 번호 이모지로 시작. 검증은 판정 이모지를 줄 맨 앞에.
- 조회수는 만 단위 축약("3.6만회").
- 항목 수: 분석영상 최대 2~3개 / 인사이트 3~4개 / 검증 2개 / 리스크 2개 / 기회 2개 / 정책 2개.
- 분석영상 선별 기준: 채널별 대표성 또는 조회수 상위, 각 항목 한 줄로 압축(제목/채널·조회수/
  핵심주장을 최대한 붙여쓰기).
- **분석영상 섹션이 최상단**(헤더 바로 다음)에 오도록 하고, 이름은 "주목 영상"이 아니라
  반드시 **"분석영상"**으로 표기.

**정확한 포맷 (골격 예시 — 850자 예산에 맞춰 실제 내용 분량을 조정할 것):**
