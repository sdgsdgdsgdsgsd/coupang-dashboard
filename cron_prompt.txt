**Step 1: 오늘 날짜 확인**
오늘 날짜를 YYYYMMDD 형식으로 확인하세요.
시스템 날짜 기준으로 KST(UTC+9) 기준 오늘 날짜를 사용합니다.

**Step 2: 영상 데이터 로드**
GitHub MCP 도구(get_file_contents)로 다음 파일을 읽으세요:
- 레포: sdgsdgdsgdsgsd/coupang-dashboard
- 경로: data/raw_videos_{오늘날짜}.json
- 파일이 없으면 어제 날짜(YYYYMMDD-1)도 시도하세요.

파일의 videos 배열에는 각 영상의 title, url, channel_name, views, description, transcript 필드가 있습니다.

**Step 3: 부동산 인사이트 직접 분석**
읽은 영상 데이터(특히 transcript 내용)를 대한민국 부동산 시장 전문가 시각으로 깊이 분석합니다.
추측을 최소화하고 실제 영상 내용 기반으로 구체적이고 실행 가능한 인사이트를 도출하세요.

분석 항목:
1. **핵심 인사이트** 5개: 여러 채널에서 공통적으로 강조하는 시장 방향, 투자 포인트
2. **시장 감성**: positive/neutral/negative + 판단 근거 1~2문장
3. **리스크 요인** 3개: 현재 부동산 투자의 구체적 리스크
4. **투자 기회** 3개: 구체적 투자 포인트
5. **주목 정책/이슈** 2개: 정책 변화, 규제 이슈
6. **채널별 주목 영상**: 채널명, 영상 제목, 조회수, 핵심 주장 1문장

**Step 4: 카카오톡 상세 알림 발송**
KakaotalkChat-MemoChat MCP 도구로 아래 형식의 상세 메시지를 발송합니다.
글자 수 제한 없이 가독성 좋고 직관적인 분석 내용을 담아주세요.
