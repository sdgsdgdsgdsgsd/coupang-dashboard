**Step 1: 오늘 날짜 확인**
오늘 날짜를 YYYYMMDD 형식으로 확인하세요.
시스템 날짜 기준으로 KST(UTC+9) 기준 오늘 날짜를 사용합니다.

**Step 2: 영상 데이터 로드**
GitHub MCP 도구(get_file_contents)로 다음 파일을 읽으세요:
- 경로: data/raw_videos_{오늘날짜}.json
- 파일이 없으면 어제 날짜도 시도하세요.

파일의 videos 배열에는 각 영상의 title, url, channel_name, views, description, transcript 필드가 있습니다.

**Step 3: 부동산 인사이트 직접 분석**
읽은 영상 데이터(특히 transcript 내용)를 대한민국 부동산 시장 전문가 시각으로 분석합니다:

분석 항목:
1. **핵심 인사이트** 5~8개: 여러 채널에서 공통적으로 강조하는 시장 방향, 투자 포인트
2. **시장 감성**: positive/neutral/negative + 판단 근거 2~3문장
3. **오늘의 핵심 키워드** Top10: 가장 많이 언급된 단어와 빈도
4. **리스크 요인** 3~5개: 현재 부동산 투자 리스크
5. **투자 기회** 3~5개: 구체적 투자 포인트
6. **주목 정책/이슈** 2~3개: 정책 변화, 규제 이슈
7. **채널별 요약**: 각 채널의 핵심 주장 (채널명, 영상 제목, 2문장 요약, 감성)

**Step 4: Gmail 이메일 초안 생성**
분석 결과를 바탕으로 Gmail MCP 도구(create_draft)로 HTML 이메일 초안을 생성합니다:
- to: ["joon309157@gmail.com"]
- subject: "📊 부동산 유튜브 인사이트 — {YYYY년 MM월 DD일} 리포트"
- htmlBody: 아래 스타일의 완전한 HTML 이메일 (인라인 CSS 포함)

HTML 구조:
1. 파란 그라디언트 헤더: "📊 부동산 유튜브 인사이트" + 날짜
2. 통계 카드: 신규 영상 N개, 커버 채널 N개, 전체 감성(긍정📈/중립📊/부정📉)
3. 🔑 오늘의 핵심 인사이트 (bullet list)
4. 📺 채널별 영상 요약 (각 영상: 제목 링크, 감성 배지, 조회수, 2문장 요약)
5. ⚠️ 리스크 요인 / 투자 기회 / 주목 정책 섹션
6. 푸터: "자동 생성된 리포트 · {날짜}"

인라인 CSS 스타일 가이드:
- 배경: #F1F5F9, 최대폭 680px
- 헤더: background:linear-gradient(135deg,#1E3A8A 0%,#2563EB 60%,#3B82F6 100%), border-radius:16px
- 카드: background:#fff, border-radius:14px, box-shadow:0 1px 4px rgba(0,0,0,.08), padding:24px 28px
- 섹션 제목: border-left:4px solid #2563EB
- 긍정 배지: background:#DCFCE7,color:#16A34A / 부정: #FEE2E2,#DC2626 / 중립: #FEF9C3,#CA8A04
- 리스크: background:#FFF7ED, border-left:3px solid #F97316
- 기회: background:#F0FDF4, border-left:3px solid #22C55E
- 정책: background:#EFF6FF, border-left:3px solid #3B82F6

**Step 5: 카카오톡 상세 알림**
KakaotalkChat-MemoChat MCP 도구로 Step 3 분석 결과를 바탕으로 아래 형식의 상세 메시지를 발송합니다.
글자 수 제한 없이 가독성 좋고 직관적인 분석 내용을 담아주세요.
